# 공포의 회전목마

같은 링크로 들어온 사람들이 한 놀이공원에 모이는 3D 멀티플레이 놀이터입니다.

- **회전목마 타기**: 빈 목마에 올라탑니다. 머리 위에 내 이름이 뜨고, 밖에서 부르면 `좋아! / 싫어! / 몰라~`로 대답할 수 있어요.
- **쫓아가기**: 울타리 밖에서 달리며 목마 옆에 붙어 외칩니다. 가까운 탑승자의 이름이 앞에 붙어서 `(이름) 너 나 좋아 싫어?!` 로 말풍선이 뜹니다.
- 언제든 오른쪽 위 버튼으로 타기 ↔ 내리기를 바꿀 수 있어요.
- 목마 0번에는 늘 빨간 코트를 입은 "한정선"이 타고 있어서 혼자 들어와도 놀 수 있어요.
- 울타리 밖에서는 NPC "직진남"이 늘 한정선을 쫓아 달려요. 30초 달리고, 6초 헥헥대며 쉬고, 다시 전력질주로 따라잡아요. 모든 접속자 화면에서 같은 위치에 보여요.
- 크리스마스 장식: 크림·금색 캐노피, 리스와 오너먼트, 꼭대기 별, 트리, 내리는 눈 (`xmas.js`).
- 음악: 캐럴 "고요한 밤"(그루버, 1818, 퍼블릭 도메인)을 합성 성악 음색으로 부르고 하프, 썰매 방울, 첼레스타가 반주합니다. 음원 파일 없이 브라우저에서 바로 연주돼요.

## 친구와 같은 방에서 만나기

- 입장 화면의 **새 코드 만들기**를 누르면 숫자 4자리 방 코드가 생기고 초대 링크(`?code=4821`)가 복사됩니다. 게임 중에는 오른쪽 위 **친구 초대**를 눌러도 됩니다.
- 친구는 그 링크로 들어오거나, 입장 화면의 **친구 코드** 칸에 숫자 4자리를 넣으면 같은 방으로 갑니다.
- 코드를 만든 사람이 목마를 타고 있으면, 코드로 들어와 **쫓아가기**를 고른 친구는 그 목마 바로 바깥에서 시작합니다.
- 코드 없이 들어오면 모두가 모이는 광장으로 갑니다.

## 서버 없이 동작하는 방식

GitHub Pages는 정적 파일만 올릴 수 있어서, 접속자끼리 WebRTC로 직접 연결합니다([Trystero](https://github.com/dmotz/trystero), 공개 Nostr 릴레이로 서로를 찾음). 그래서 별도 서버 비용이 없습니다.

- 한 방에 10~20명 정도가 적당합니다. 사람이 많으면 방을 나눠 주세요.
- 학교나 회사처럼 방화벽이 강한 네트워크에서는 서로 안 보일 수 있어요. 이때도 게임은 혼자 모드로 동작합니다.
- 회전목마 각도는 각자 기기 시계로 맞춥니다. 시계가 크게 틀린 기기는 목마 위치가 조금 다르게 보일 수 있어요.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소(예: `merry-go-round-chase`)를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/merry-go-round-chase/` 로 접속해서 링크를 공유하세요.
